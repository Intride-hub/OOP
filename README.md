Каждая лабораторная — отдельная папка, которая запускается сама по себе:
`cd src/lab01` → `python demo.py` (в ЛР-7 — `python main.py`). Нужен Python 3.10 или новее.

Как развивается код от работы к работе:

| ЛР | Что добавилось |
|---|---|
| 1 | `Car`: закрытые поля, свойства, сеттер пробега, `drive()`, `trip_cost()`, ремонт |
| 2 | `Fleet`: добавление, удаление, поиск, `len`, `for`, индексы, сортировка, выборки |
| 3 | `Taxi` и `Truck` наследуют `Car`, общий метод `display()`, выборка по типу |
| 4 | интерфейсы `Printable` и `Earnable` (ABC), функции, которые знают только интерфейс |
| 5 | `sort_by`, `filter_by`, `apply` и стратегии в `strategies.py` |
| 6 | аннотации типов, `TypedCollection[T]`, протоколы `Displayable` и `Priced` |
| 7 | CLI в три слоя, свои исключения, сохранение в JSON |
