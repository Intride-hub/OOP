# ЛР-3 — Наследование и иерархия классов

## 1. Цель работы
Освоить наследование, `super()`, переопределение методов и атрибутов класса,
`isinstance()`, полиморфизм без условий и интеграцию иерархии с коллекцией.

## 2. Описание иерархии
```
Car  (base.py)              обычная легковая машина
 ├── Taxi  (models.py)      + тариф, выручка, число поездок; complete_ride()
 └── Truck (models.py)      + грузоподъёмность, текущий груз; load(), unload()
```
**Базовый класс** `Car` — из ЛР-1, дополнен общим интерфейсом поведения:
`display()` (карточка) и `trip_cost(distance)` (стоимость поездки = топливо × цена).

**`Taxi`**: новые атрибуты `_tariff`, `_earnings`, `_rides`; новый метод `complete_ride()`;
переопределены `trip_cost()` (посадка + тариф × км), `display()`, `__str__`, `__repr__`,
атрибут класса `CATEGORY`.

**`Truck`**: новые атрибуты `_max_load`, `_current_load`; методы `load()`, `unload()`;
переопределены атрибуты `FUEL_CONSUMPTION = 25`, `CATEGORY`, методы `fuel_needed()`
(расход растёт с грузом), `trip_cost()` (+ дорожный сбор через `super()`), `display()`, `__str__`.

Различие: `Taxi` считает поездку как доход пассажира, `Truck` — как расход владельца
с учётом груза. Оба **не копируют** код `Car` — конструкторы вызывают `super().__init__()`.

Интересный момент: `drive()` не переопределён, но в `Truck` он списывает больше топлива,
потому что внутри вызывает `self.fuel_needed()`, а его `Truck` переопределил.

**Коллекция** (`collection.py`): хранит любые `Car` и потомков; `get_only(cls)`,
`get_only_taxis()`, `get_only_trucks()`, `get_only_plain_cars()`,
`total_trip_cost()` (полиморфный вызов без `if isinstance`).

## 3. Демонстрация работы (`python demo.py`)
1. Объекты трёх типов, унаследованные и собственные методы, переопределённые атрибуты класса.
2. Переопределённый `__str__`, `isinstance()`/`type()`/`issubclass()`, работа `fuel_needed`.
3. Полиморфизм: `trip_cost(100)` даёт разное; такси зарабатывает через `complete_ride()`.
4. Одна коллекция — разные типы; выборки по типу; поиск и сортировка из ЛР-2.
